# -Ask-Buddy---AI-QnA-Chatbot
Ask Buddy is an AI-powered conversational chatbot built using **LangChain**, **Google Gemini API**, and **Streamlit**.   It allows users to interact with an intelligent assistant that can answer questions and maintain conversation context using chat memory.  ---
## 🚀 Features

- 🤖 AI-powered question answering
- 🧠 Conversational memory management
- 🔗 LangChain integration
- ✨ Google Gemini LLM integration
- 💬 Chat-style interactive interface
- ⚡ Real-time responses using Streamlit
- 🔐 Secure API key management using environment variables

---

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Framework:** Streamlit
- **LLM Framework:** LangChain
- **AI Model:** Google Gemini
- **Environment Management:** Python-dotenv
